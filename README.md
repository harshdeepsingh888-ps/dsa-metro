# DSA Metro

Learn data structures and algorithms from zero to dynamic programming, laid out as a metro map.

- **18 stations on 4 lines**: Big-O to DP, each with a story, an interactive demo, C++ and Python code, a quiz and LeetCode practice.
- **DP table games**: fill in Climbing Stairs, House Robber, Coin Change, Grid Paths, LCS and Knapsack tables cell by cell.
- **Study guide**: beginner, intermediate and advanced levels with LeetCode, Codeforces, CSES and AtCoder problems, company-style question sets, a season plan to placements, and a revision list.
- **XP, ranks and streaks** to keep you going.

Live site: https://harshdeepsingh888-ps.github.io/dsa-metro/

## Files

- `dsa-metro.html` is the source. It is also published as a claude.ai artifact, where progress syncs to your account and the hint and doubt boxes use Claude.
- `index.html` is generated from it for static hosting. On the hosted site, progress is saved in your browser and the Claude features are hidden.

After editing `dsa-metro.html`, rebuild and push:

```bash
node build.mjs
git add -A && git commit -m "Update site" && git push
```
